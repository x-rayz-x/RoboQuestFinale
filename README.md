## About RoboQuest

RoboQuest is an interactive learning platform designed to help kids and beginners explore the world of programming, robotics, and technology in a fun, engaging, and structured way.
From simple Python loops to exciting Arduino projects, RoboQuest makes coding accessible for everyone.

You can:

• Watch YouTube tutorials categorized by difficulty and topic

• Try hands-on coding projects with real-world applications

• Earn achievements and badges for your progress

## Privacy

RoboQuest is COPPA-compliant, ensuring a safe learning experience for children.

All user data is handled securely using Supabase for authentication and storage.
